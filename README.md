# 📚 Mini App «Книга на вечір» — Простір корисного контенту

Готовий комплект для Telegram Mini App у стилі каналу «Простір корисного контенту».

## Що всередині

- `frontend/` — Mini App для GitHub Pages.
- `frontend/data/` — 15 TXT-файлів категорій, у кожному по 5 книжок.
- `frontend/categories.json` — список категорій.
- `assets/logo.svg` — стилізований логотип у чорному/золотому оформленні каналу.
- `worker/` — серверна частина для технічного ліміту 10 безкоштовних рекомендацій на добу та Telegram Stars Premium.
- `worker/schema.sql` — структура D1-бази.
- `.github/workflows/pages.yml` — автоматична публікація Mini App через GitHub Pages.
- `docs/` — покрокова інструкція.

## Важливо про Premium

Сам GitHub Pages не може безпечно рахувати запити користувача або підтверджувати оплату Telegram Stars. Тому в комплекті є Cloudflare Worker + D1: GitHub залишається місцем зберігання коду та публікації фронтенду, а Worker виконує серверну перевірку Telegram `initData`, добовий ліміт і обробку платежів.

Telegram офіційно підтримує Stars-підписки для Mini Apps; для періоду підписки використовується 2 592 000 секунд (30 днів). Після успішної оплати бот отримує `successful_payment`, що дає змогу зберегти строк Premium на сервері.

## Безпека

Не вставляйте токен бота в `frontend/config.js` або GitHub-репозиторій. Токен зберігається тільки як Cloudflare Worker Secret `BOT_TOKEN`.

## Джерело структури категорій

Категорії підібрані за логікою актуального каталогу YAKABOO: художня література, бізнес/економіка, саморозвиток, дитяча література, батьківство, історія, біографії, здоров’я, мистецтво, наука/техніка, психологія тощо. У Mini App вони згруповані в 15 зручних тематичних полиць.

Рецензії у TXT-файлах — авторські редакційні тексти цього комплекту, а не копії описів магазинів чи видавництв.
