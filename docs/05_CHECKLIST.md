# 5. Перевірка перед запуском

1. GitHub Pages відкриває Mini App по HTTPS.
2. `frontend/config.js` містить реальну адресу Worker.
3. Worker відповідає на `/health`.
4. D1 створена, `schema.sql` виконаний.
5. `BOT_TOKEN` і `WEBHOOK_SECRET` задані як Secrets.
6. `getWebhookInfo` показує правильний webhook.
7. У BotFather створений Web App `knyha` з URL GitHub Pages.
8. Відкриття `https://t.me/ВАШ_БОТ/knyha` запускає застосунок у Telegram.
9. Перша рекомендація повертається з вибраної категорії.
10. Після 10 безкоштовних рекомендацій користувач не бачить наступну книгу й отримує Premium-екран.
11. Premium створює оплату на 10 Stars / 30 днів.
12. Після успішної оплати Worker записує підписку в D1.
13. Під час активного Premium рекомендації продовжують працювати без добового обмеження.
14. Ранковий URL «Щасливий день» і URL книги залишаються різними.
